「订单完成」是结算的唯一入口时点，不同商品判定方式不同 —— 这是本轮更正的核心。

3结算时点与三种月份口径

订单完成 → +10 个自然日 → 满足结算 → 实际打款，三段时点天然错位，这是应付与实付对不上的主因之一。

T0 订单完成图书确认收货
/ 999 原生营付款成功
T0 +10 自然日满足结算
进入可发状态
支付月打款人力 / 财务实际付款
负向冲减退款产生反向流水
① 订单月
用户下单的月份。应付表无此字段，需回到来源单据 ID 对应的订单表取。
② 结算月
满足结算的月份。本表唯一有值的月份字段（9 月样本 610 行全部为「满足结算」）。
③ 支付月
实际打款的月份，来自人力 / 财务实付记录。与订单月天然错位。
趋势图必须明确标注采用哪种口径，看板上要能一键切换。三种口径混用是图表对不上的常见原因。

人力支付 · 认领订单
由人力从应付中认领并发放。不是按「是否有企微」自动判定，而是按当月认领结果。
9 月样本：288 行 / 47.2% / ¥17,953.20。
财务支付 · 其余订单
未被认领的走财务通道，经三方平台发放，含平台费用。
9 月样本：322 行 / 52.8% / ¥13,449.70。
旧规则作废：此前描述为「有企微＝员工→人力付；无企微＝非员工创作者→财务付」。10-22 更正为认领制后，员工 / 非员工不再等于支付通道，二者只能作为统计维度，不能作为路由规则。系统打通后此过渡机制应可撤销。

5拆商品 + 付没付标记

本轮两条更正都落在实付侧：实付不能只停在「谁付的」，还要能拆到商品；应付与实付是同一份数据，只差一列标记。

应付 vs 实付：同源关系

对比项应付实付
数据来源分佣流水（订单级）同一份明细，不是另一套数据
差异字段—多一列 「这笔单子付没付」 标记
成立时点下单即成立满足结算 + 过闸门 + 实际打款
商品拆分已含商品维度必须同样能拆商品（10-22 新增要求）
核对方式先按「付没付」标记分组，再在组内做金额差额核对 —— 不要按两套数据硬关联

按商品拆开看，而不是只看总额。

6不发放闸门：造成「应付有 · 实付无」的情形

过了 S4 闸门才可能发放；被拦下的计入差异，但不等于异常。

官方号 / 白名单
官方账号不参与结算。白名单清单来源与维护方待确认。
班主任的 999 订单
999 属岗位职责内，不额外发放 APP 佣金。是否适用于其他岗位待确认。
公职人员
无法签约，因此无法走财务发放。
拒收 / 拒绝收款
创作者本人拒绝收款。
公益直播等其他场景
口述提到但未列全，完整清单待补，不写成自动规则。
尚未到支付周期
订单完成后 +10 自然日未到，本期对不上、下月出现。
页面只做提示与筛选，不自动判定异常、不自动归类原因。

7特殊场景：发放角色切换（分段结算）

人的员工 / 创作者身份可能在月中切换，佣金按行为发生时的身份分段结算。

场景 A · 员工 → 离职 → 次月分佣
在职期间：按工资结算发放。
离职之后：按创作者规则结算发放。
同一个人同一个月出现两种结算方式。
场景 B · 创作者 → 入职 → 次月分佣
暂无此类案例。
处理方式：先在流水上记录发放角色，待实际发放时再确认具体方式。
不为未发生的场景写死规则。
面板实现要求
流水上保留 「发放角色」字段；切换月的人员分段展示（在职段 / 离职段），支持按段筛选与导出。

8延伸动作：素人挖掘 + 提醒签约

结算数据除了核对，还要反向喂给业务 —— 本轮新增「提醒签约」。

素人挖掘

从结算流水中识别未接触的野生创作者，给 IP 组反向线索（一心 / 冠鹏 / 博轩，12 月 100 个 IP 目标）。
孵化 / 素人维度反向线索清单

提醒签约 10-22 新增

把未签约名单直接推给对应小组助教，由助教催签约 —— 未签约是「暂缓发放」的主因之一。
未签约名单推送给小组助教签约推进结果回写
两者都属于结算数据的延伸用法，不是结算主链的必经节点。

10遗留待确认

10-22 本轮已解决 3 条（结算时点、商品完成判定、支付通道），以下仍需业务方书面确认后才进入开发。

  1. 字段缺失：应付表无「确认收货 / 签收时间」字段，+10 自然日只能按订单时间粗估，需数据侧补字段。阻塞精确排期
  2. 商品清单：是否只有图书与 999 原生营两类；图书按书名拆 4 本的书名口径。
  3. 白名单 / 官方号清单：后台白名单功能不完善，当前清单从哪来、由谁维护。
  4. 班主任 999 不发放：判定字段是什么，是否覆盖全部 999 订单，是否适用其他岗位。
  5. 不发放场景完整性：口述提到「公益直播等」，完整清单待补。
  6. 6.8% 平台费用：是税费还是手续费？计算基数？是否仅财务侧？是否计入本看板成本。
  7. 三种月份口径：趋势图默认用哪一种，是否需要一键切换。
  8. 人员组织：6 个队正式名称、非员工是否归队、岗位完整分类。
  9. 叫法统一：对外称「999 原生营」还是「999 训练营」。
已解决项：+10 自然日统一适用（原 +10 工作日作废）；图书 / 999 原生营完成判定；过渡期认领制取代企微判定；应付实付同源 + 付没付标记；素人挖掘追加提醒签约。
